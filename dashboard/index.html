How the implied value is derived — the model, stated in full

Implied value is this board's own claim, computed only from the snapshot's figures; it is not a prediction that a token will be issued. Figures are the snapshot's record: a protocol is said to record no token, never to have none. Farm plans are starting points, not financial advice — check each protocol's own pages before acting.
